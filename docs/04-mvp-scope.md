# MVP Scope

## Objectif du MVP

Construire une plateforme simple de veille cyber pour PME capable de collecter des menaces, les analyser, calculer un score de risque et générer des alertes.

## Fonctionnalités V1

1. Collecte de données Threat Intelligence
2. Normalisation des données
3. Risk scoring
4. Stockage des menaces
5. API backend
6. Dashboard simple
7. Fiches réflexes
8. Alertes simples

## Hors scope pour V1

- SIEM complet
- Collecte massive de logs internes
- Déploiement Kubernetes
- IA avancée deep learning
